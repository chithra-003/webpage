Computer is an electronic device used to store, process and display information. Computer works mainly though Input - Processing - Output. CPU ( Central Processing Unit ) ia called the brain of th computer. Keyboard is used to enter text and numbers. Mouse is used to point, select and open items. Moniter displays the output from the computer. Printer produces information on paper. RAM (Random Access Memory) is temporary memory. ROM (Read Only Memory) stores permanent instructions. Hard Disk/SSD is used to store files and data. Hardware means the physicalparts of a computer. Software means the programs/ intructions that run on a computer. Operating System(OS) manages the computer's hardware and software. Common computer uses: eduction, bsnking, Communication, business, entertainmentand research.

Email is used to send and receive electronic messages. Files is a collection of stored data. Folder is used to organize and store files.
